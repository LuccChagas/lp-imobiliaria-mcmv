# LP — Imobiliária (segmento Minha Casa Minha Vida)

Landing page de captação para gerente de vendas que trabalha com empreendimentos
novos no segmento MCMV.

O projeto ainda não foi iniciado. **Leia o [CLAUDE.md](./CLAUDE.md) antes de começar** —
ele define stack, arquitetura, direção visual, tom de voz e as regras de compliance
do segmento imobiliário.

## Primeiro passo

```bash
npx create-next-app@latest . --typescript --tailwind --eslint --app --src-dir \
  --import-alias "@/*" --use-npm --no-turbopack --yes
```

- [ ] Números reais (famílias atendidas, tempo de mercado)
